A one-sentence defence from a house cat after knocking a glass off the table — a small deterministic Python program that writes the cat's excuse to `/output/entry.txt` for make.fun's "Five Seconds to Explain the Glass" bounty. No apology, no confession: the glass parked itself in the cat's sunbeam and acted like it paid rent, so it got evicted.

## Run it

```sh
python3 main.py
```
